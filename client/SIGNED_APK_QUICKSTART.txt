KROK 1: Zjistí si, máš-li keystore
──────────────────────────────────────
Spusť v terminálu:
  ls ~/.android/nexus-release-key.jks

- Pokud vidíš cestu → máš keystore (SKOČIT NA KROK 3)
- Pokud "No such file" → musíš vytvořit keystore (KROK 2)


KROK 2: Vytvoř nový keystore (JEN POKUD NE MÁTEŠ)
──────────────────────────────────────────────────
Spusť:
  keytool -genkey -v -keystore ~/.android/nexus-release-key.jks \
    -keyalg RSA -keysize 2048 -validity 10000 -alias nexus-key

Odpověz na otázky:
  Keystore password: [vymysli heslo - NAPIŠ SI HO!]
  Key password: [stejné heslo]
  First name: [tvoje jméno]
  Last name: [tvoje příjmení]
  Organization: [tvá firma/jméno]
  City: [město]
  State: [stát]
  Country: [CZ, US, atd]

✅ Hesla si zapamatuj - budeš je potřebovat!


KROK 3: Nastav Environment Variables
──────────────────────────────────────
V terminálu spusť (NAHRAĎ HESLO!):

  export NEXUS_KEYSTORE_PATH=~/.android/nexus-release-key.jks
  export NEXUS_KEYSTORE_PASSWORD="TVOJE_HESLO_ZE_KEYSTORE"
  export NEXUS_KEY_ALIAS="nexus-key"
  export NEXUS_KEY_PASSWORD="TVOJE_HESLO_ZE_KEYSTORE"

Příklad:
  export NEXUS_KEYSTORE_PASSWORD="MySecurePass123!"
  export NEXUS_KEY_PASSWORD="MySecurePass123!"


KROK 4: Postav APK
─────────────────
Spusť:

  cd /Users/zdenekdias/.gemini/antigravity/scratch/nexus-hub/client/android
  ./gradlew clean
  ./gradlew assembleRelease

⏳ ČEKEJ 5-15 MINUT (první build je pomalejší)
   Přidělej si čaj ☕


KROK 5: Najdi APK
─────────────────
Až se build skončí, najdeš APK tady:

  ~/Downloads/ nebo
  /Users/zdenekdias/.gemini/antigravity/scratch/nexus-hub/client/android/app/release/Nexus-Relay-v*.apk

Věš že to funguje když vidíš: "BUILD SUCCESSFUL" na konci


KROK 6: Instaluj na telefon
────────────────────────────
Máš dva způsoby:

A) Přes USB (nejrychlejší):
   - Připoj Android telefon USB kabelem
   - Na telefonu zapni USB Debug (Settings → Developer Options → USB Debugging)
   - Spusť:
     adb install -r /Users/zdenekdias/.gemini/antigravity/scratch/nexus-hub/client/android/app/release/Nexus-Relay-v*.apk

B) Ručně:
   - Zkopíruj APK na Google Drive / Email / USB
   - Otevři na telefonu a klikni "Instalovat"
   - Dovolí neznámé zdroje (Settings → Security)

⚠️ ČASTÉ PROBLÉMY & ŘEŠENÍ
═══════════════════════════════════════════════════════════════════════════════

PROBLÉM: "Keystore not found"
ŘEŠENÍ: Vytvoř nový keystore (KROK 2)

PROBLÉM: "Build failed"
ŘEŠENÍ: Zkus ./gradlew clean a pak znova

PROBLÉM: "APK Not Generated"
ŘEŠENÍ: Podívej se do android/app/build/outputs/apk/release/
        Pokud nic: ./gradlew clean a zkus znova

PROBLÉM: "NEXUS_KEYSTORE_PASSWORD not set"
ŘEŠENÍ: Ověř export variables: echo $NEXUS_KEYSTORE_PASSWORD

PROBLÉM: "Installation Failed"
ŘEŠENÍ: adb install -r (s -r flag = force replace)
